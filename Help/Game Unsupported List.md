# Game Unsupported List

> [!WARNING]
> Obviously not every game is going to be listed, but a general rule should be if your game requires [Memory Integrity/Core Isolation](https://support.riotgames.com/en-us/riot/support-tools/enable-memory-integrity) then IMOD Disabler won't be supported.
>
> TLDR: In order to run [RWEverything](https://rweverything.com/download/) we must disable [Microsoft's Vulnerable Driver Blocklist](https://www.ninjaone.com/blog/enable-or-disable-microsoft-vulnerable-driver-blocklist/), but to disable the driver block list, **Memory Integrity/Core Isolation** needs to be disabled!
>
